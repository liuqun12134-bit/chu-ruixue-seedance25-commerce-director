# 参考视频一次维护脚本与动作

明确“分析入库/整理参考”即可执行。AI主动问：“这些视频分别是什么品类？如果都是同一品类，统一告诉我即可。”本批次已说明则不重复问；混合批次按编号分组，不能整批猜成面霜。无需先指定目标商品。

用户不知道则标来源品类unknown，先完成可观察部分，不能充当确定分类。来源品类与适用品类分开；借演法不借包装、用量和效果强度。有目标产品时用其规则判断可迁移性。

## 同一视频，两类产物

1. 核对来源、时长、实际观看/抽帧/听审方式及重复；同一拍摄的剪辑、转载、转码不是独立证据。
2. 完整脚本：先看全片，记录目的、原始起点、实际顺序、使用、效果展示和收尾；区分剪辑省略与连续动作。按[脚本维护](script-maintenance.md)提炼必需/可选环节、依赖、可换序段和结果保持。
3. 动作：起点→发起→接触/变化→结束→衔接，保存真实时间可靠性和原片证据；填写五类适用信息，未知不当不限。
4. 效果展示：分清膏痕与妆效、光泽与曝光、部位本身色差与前后效果；迁移展示方式，不把竞品视觉变化写成本品事实。
5. 脚本和动作共用来源，action_options引用动作ID，不复制视频制造独立证据。只见局部动作时可仅入动作，脚本draft并标缺环节，不凑假完整脚本。

旧分析可以转成路线，但注明本次未重新观看；不能把零散单元自动拼成已观察的完整流程。口述脚本另走维护入口，不需要视频。

## 人物和完成标准

确认是初瑞雪本人且未被用户排除时，按[人物格式](performance-format.md)保存原话、语气、动作关系。未听审/未核实对应关系为pending；其他人和AI成片不能当本人习惯。

运行catalog.py reindex、validate、review。按视频交付确认品类、新增/更新脚本与动作、人物表现、重复和待核查项。结构检查不认证口型、效果或生成质量。旧demo-library只作来源保留，不新增产品/品类两套重复动作。
