# 当次成片诊断与记录

先读取用户点出的成片、输入、实际提交稿和原声版本，结合其反馈。已确认的信息不重复问。按“观察到什么 → 有哪些可能原因 → 本次怎样改 → 怎样验证”说明，不能从文字提示词推出模型必然按要求执行。

本次优先检查：

- 动作是否符合已选方案，是否又变成长时间举品或同一侧脸反复推抹；若提示词本来如此，先改编排，若稿中已不同而成片未执行，则标执行偏离。
- 表现是否与可靠本人例子相符；没有本人证据时不能判断为某一具体习惯不匹配。与用户一起判断“像不像本人”，避免把动作多当作自然。
- 动作是否只有功能任务、缺少合理收势/停顿；加的是有上下文的自然过渡，不增加随机动作数量。
- 声音/嘴部是否重复、漏句或失配，按[音频流程](audio.md)处理。

首参考图相似度优化、偶发镜像或换手错误按用户当前优先级处理，默认不为它们扩大改造范围。基础持物/接触连续性仍须检查；实际发现使方案不可能成立的冲突要说明。

把本次素材哈希、所选路线/单元、提交稿、可见结果、用户评价和未验证原因放在任务目录。生成成功只能说明这次制作可用，不能当作初瑞雪本人习惯证据。复读归因也不能靠一条成功/失败就确认。

用户要求改稿时交完整修订稿，保留满意部分和原来的实际使用目标；不要只加禁词、只发补丁或删掉所有使用动作。需要生成验证时明确尚未进行，本技能不自动付费或重试。
