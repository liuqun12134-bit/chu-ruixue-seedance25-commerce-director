# 脚本维护与重排

两个入口：参考视频按[入库流程](ingestion.md)主动问品类并分析完整路线；用户口述新增/修改/停用则直接维护，不要求视频。用户设计为user_authored，AI补充设计为authored_method；未测试标untested，不冒称原片观察或生成验证。停用设enabled=false保留证据。缺关键身份/目标才问，不额外问是否保存。

脚本保存目标和必需/可选环节，不固定每秒动作。每段有进入状态、动作候选、完成状态、后续保持和验收。depends_on只写真实因果，不把“包装→手背→脸”固定成唯一顺序。source_sequence保留原片顺序；改编与观察分开。initial_state_satisfies说明首帧已涂好时如何承接。

use路线要求看清使用结果时，effect_required=true，效果展示阶段必须为required。效果强度与持续要求读取本品规则。脚本action_options可为空表示尚无视频动作支撑，不能伪造引用。

先理解音频语义，再重排可换序环节。audio_intents是优先匹配位置，不是关键词触发器；一句可以无动作，一个操作可跨句。开头讲效果可开始使用、相邻句段展示结果；不能让未涂部位先变白。没有成分话术不强塞固定“成分展示”；本次必需的人参展示可放在适合的介绍或过渡段，不新增台词。

不能颠倒物理因果、悄悄删用户核心演示、把长流程等比压成不真实的短片。时长不足先减可选项，仍冲突则明确提出最少调整。

修改保存history、依据及验证状态。检查依赖无环、动作引用存在、必需效果阶段保留。用户只改某段时保留其他要求。单次成片成功不等于普遍有效。
