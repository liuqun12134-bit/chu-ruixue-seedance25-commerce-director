# 从产品和原声编排

先读真实素材角色和首帧持物、开合、已有膏痕、配件、承托。镜像未知用画面左右。studio.py resolve-product按用户ID/绑定图确定目标；reference_only对标商品不能当新品。缺核心规则进入[产品采访](product-interview.md)。

按[音频流程](audio.md)核对版本、长度、语义顺序、语气和停顿；ASR估计不是听审。保留原声，脚本服务台词。

## 先路线与交流意图，再动作

1. 读产品规则与失败记录：正式规则约束本次，原因假设只提示待核查，不自动禁止转头等动作。
2. 使用 `studio.py scripts --product-id PRODUCT --mode talk` 查询纯口播；使用模式改为 `--mode use`，比较目标、首帧、时长相容的路线。缺脚本可设计补充，但不称来自视频库。
3. 获取必需/可选环节与完成状态，按原声重排可换序段，保留操作依赖；依据[共用人物表现](performance-direction.md)先确定主要语义段的交流意图与态度，再考虑动作，不逐词触发。
4. studio.py actions按本次talk/use模式查询，结合交流意图与操作目标选择候选，检查排除理由和needs_review；五标签只辅助，仍核对实际手位与证据。未知不等于不限，同款来源不免除条件检查。
5. catalog.py performances查ready本人表现，核对语义、语气、持物；pending不能编成已确认习惯。没有相容关联时，按本次原声和手位设计交流表现并标明设计补充，不因召回为空取消表演。

内部记录“语义段→交流意图/态度→脚本环节→表情与视线→手部任务和过渡→起止状态/后续保持→依据”。有库动作则记录ID，无库动作明确设计来源。按[共用人物表现](performance-direction.md)处理操作、交流、过渡的优先级；兼容时并行，手忙或接触精细时减去竞争动作。

## 通用编排规则

以下为2026-11-09用户确认的设计要求，可跨人物选用，不作为初瑞雪本人习惯证据；本轮未做生成测试。

- **购买引导：**原声表达“有需要自己拍吧”“赶紧拍吧”“抓紧搂吧”等购买意图时，若手位与时机合适，可用空闲手朝观众视角的画面左下角简短指引后自然收回。按完整语义段安排，不逐词触发、不每句重复；取膏、推匀或必要效果展示优先，可顺延到相邻合适位置或省略。不新增小黄车图标，不改动原声。
- **产品暂放：**产品不必全程持握或出镜。完成当前必要的识别、取用或展示后，可放到桌面或画外可承托位置，腾出手继续推匀已有膏体、展示效果或交流。先给出可执行的放置方位；手带产品移出、放稳，再空手返回。开罐不为暂放强制回盖，开合与盖/内片去向按实际状态安排。
- **产品取回：**后续讲解需要时，从此前记录的位置取回同一产品；不强制结尾举品，不为了凑动作反复取放。保持容器、开合、配件与已经完成的肤面效果连续，避免画外取放变成瞬移或效果重置。

用途标签使用“购买引导”“产品暂放”“产品取回”，写在动作的applicability.purpose中；不新增“通用”品类。先按用途召回，再核对品类、质地、包装、部位、起止状态与手位；已有记录只补相符标签，不因补标签升级draft或生成验证状态。只在产品已放下后开始涂抹、没有取放过程的动作，不标成取放动作。

```text
python scripts/studio.py actions --mode talk --purpose 购买引导
python scripts/studio.py actions --product-id PRODUCT --mode use --purpose 产品暂放
python scripts/studio.py actions --product-id PRODUCT --mode use --purpose 产品取回
```

新设计的购买指引只在purpose维度限制用途，其余四维不限且说明与动作无关；实际空闲手、路径和时机仍是必要起始条件。产品取放沿用原记录的适用限制，不自动推广所有包装。拍摄表记录放置方位、开合/配件、手位、肤面效果及后续保持；没有真实原片依据的补充衔接标为设计。

## 牙齿外观与连续性

2026-11-13用户提供同事的人参霜边讲边用、素颜霜纯口播提示词，并亲自观看成片后确认大门牙问题已解决。2026-11-15用户同意将共同的口型写法用于本技能talk与use的默认规则，替代2026-11-10仅约束牙型、允许自然露门牙的默认策略。依据为用户对该次成片的确认；原视频、参考图和生成参数未随本次维护归档，不能声称已由AI独立复核、每句均不露齿或其他质量项全部通过，也不能推定是初瑞雪本人的真实习惯。

每份正式稿在素材与起始状态说明之后、详细动作之前，集中写出口型要求。沿用成功稿的以下表达，可按当次明确要求调整，但不能精简成一句“不要大门牙”：

> 口型优先：全程上下门牙都不外露，尤其上唇要自然垂覆在上门牙前方。说话时唇颌随原声小幅自然开合，上唇不上翻，嘴角不横向拉扯，不咧嘴笑，不突然大张嘴。重音用眼神和眉毛表达，停顿时自然合唇。牙齿结构保持正常，不生成两颗宽大、过长或向前突出的兔牙。保持原来的唇形和脸型，避免抿嘴僵住、删除牙齿或用模糊遮挡。唇形跟随完整原声，不改词、不变速、不补说、不复读尾句。手和产品不遮住嘴部来掩盖口型。

人物参考图确有露齿照片时，写明只参考五官、唇形及可辨认的口腔结构，不模仿其中的张嘴幅度和露齿姿势；没有这种参考时不虚构。真实首帧或当次要求与默认口型明显冲突时，说明并处理冲突，不编造闭口首帧。

亲切、询问和强调通过相容的眉眼、轻微点头或适当手势表达，不在后文追加露齿笑、翻上唇或大幅张嘴。只约束嘴部相关表现，保留正常眨眼、呼吸、头肩调整、手部交流和必需产品操作；不把全身动作一并压小，也不增加原声没有的重音或情绪。

当次用户明确要求露齿或其他口型时，以当次要求调整整份稿，不同时保留冲突的“不露门牙”条款；牙齿仍按本人可辨认结构保持比例协调与连续一致，不删牙、不把所有牙齿改成等大、不变脸。

成片按[口型复查](review.md#口型与牙齿复查)分别验收门牙外露、嘴部自然度、原声同步及身份保持。用户确认的本次成功保留为该案例结果，后续素材逐条验收；提示词符合要求不等于新成片已经达标。

## 选方案与验收

默认三套短方案，写重点、开头/中间/结尾、关键结果、来源与限制。改变实质路线，不只换左右脸；不足三种不凑数。用户已选/要求直接完整稿时直接执行。talk不强转use，上脸不暗改手背。

选定后交拍摄表和完整稿，不增审批。拍摄表按[交付格式](output-format.md)列语义与交流意图、可见表现、手部任务与过渡、状态保持和验收点（可靠才写精确时间）。转头展示的验收是“效果仍存在并看清”，不是“头转了”。

产品效果以本品依据为准，膏痕消散不等于妆效消失，光泽不证明吸收/不黏，长期功效不瞬变。入口能力先核对，未上传参考不能虚构@视频。成片按表复查，失败走[失败分析](review.md)。
