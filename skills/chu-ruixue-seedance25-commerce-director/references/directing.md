# 从产品和原声编排

先读真实素材角色和首帧持物、开合、已有膏痕、配件、承托。镜像未知用画面左右。studio.py resolve-product按用户ID/绑定图确定目标；reference_only对标商品不能当新品。缺核心规则进入[产品采访](product-interview.md)。

按[音频流程](audio.md)核对版本、长度、语义顺序、语气和停顿；ASR估计不是听审。保留原声，脚本服务台词。

## 先路线再动作

1. 读产品规则与失败记录：正式规则约束本次，原因假设只提示待核查，不自动禁止转头等动作。
2. studio.py scripts --product-id PRODUCT --mode use，比较目标、首帧、时长相容的路线。缺脚本可设计补充，但不称来自视频库。
3. 获取必需/可选环节与完成状态，按原声重排可换序段，保留操作依赖；不逐词触发。
4. studio.py actions --product-id PRODUCT --mode use，检查候选、排除理由和needs_review；五标签只辅助，仍核对实际手位与证据。未知不等于不限，同款来源不免除条件检查。
5. catalog.py performances查ready本人表现，核对语义、语气、持物；pending不能编成已确认习惯。没有则明示设计补充。

内部记录“语义段→脚本环节→动作ID→起止状态→后续保持→依据”。操作、交流、过渡可并行，不用随机手势或反复揉脸填时间。

## 通用编排规则

以下为2026-11-09用户确认的设计要求，可跨人物选用，不作为初瑞雪本人习惯证据；本轮未做生成测试。

- **购买引导：**原声表达“有需要自己拍吧”“赶紧拍吧”“抓紧搂吧”等购买意图时，若手位与时机合适，可用空闲手朝观众视角的画面左下角简短指引后自然收回。按完整语义段安排，不逐词触发、不每句重复；取膏、推匀或必要效果展示优先，可顺延到相邻合适位置或省略。不新增小黄车图标，不改动原声。
- **产品暂放：**产品不必全程持握或出镜。完成当前必要的识别、取用或展示后，可放到桌面或画外可承托位置，腾出手继续推匀已有膏体、展示效果或交流。先给出可执行的放置方位；手带产品移出、放稳，再空手返回。开罐不为暂放强制回盖，开合与盖/内片去向按实际状态安排。
- **产品取回：**后续讲解需要时，从此前记录的位置取回同一产品；不强制结尾举品，不为了凑动作反复取放。保持容器、开合、配件与已经完成的肤面效果连续，避免画外取放变成瞬移或效果重置。

用途标签使用“购买引导”“产品暂放”“产品取回”，写在动作的applicability.purpose中；不新增“通用”品类。先按用途召回，再核对品类、质地、包装、部位、起止状态与手位；已有记录只补相符标签，不因补标签升级draft或生成验证状态。只在产品已放下后开始涂抹、没有取放过程的动作，不标成取放动作。

```text
python scripts/studio.py actions --mode talk --purpose 购买引导
python scripts/studio.py actions --product-id PRODUCT --mode use --purpose 产品暂放
python scripts/studio.py actions --product-id PRODUCT --mode use --purpose 产品取回
```

新设计的购买指引只在purpose维度限制用途，其余四维不限且说明与动作无关；实际空闲手、路径和时机仍是必要起始条件。产品取放沿用原记录的适用限制，不自动推广所有包装。拍摄表记录放置方位、开合/配件、手位、肤面效果及后续保持；没有真实原片依据的补充衔接标为设计。

## 牙齿外观与连续性

2026-11-10用户要求在提示词规则中加入“牙齿整齐，不能出现大门牙”。此项为用户指定的外观设计要求，不是初瑞雪真实牙型的观察结论，也不代表已验证能消除Seedance牙齿随机变化。

口播正式稿默认在人物保持部分加入以下要求，可结合本次素材精简：

> 牙齿自然整齐，大小与口腔和面部比例协调；上排门牙保留正常的牙位大小差异，不出现异常宽大、过长或向前突出的夸张门牙。说话过程中，可见牙齿的形态、排列和相对大小保持连续一致，随嘴唇开合自然显露与遮挡，不突然变大、变形或粘连成整块白片。

不把“没有大门牙”解释为所有牙齿等大、删掉门牙、强制闭嘴或全程不露牙；保留自然发音及唇颌同步，不顺带要求整排纯白假牙或改变脸型。真实参考清楚时，以本人牙型为身份依据，避免模型额外夸大；若参考本身与用户要求明显冲突，说明冲突，不暗自改成另一套牙型。

验收需查看连续说话画面，区分自然露牙范围变化与牙齿结构漂移；只有提示词符合要求不能声称成片已达标。该规则不自动把所有表情改为小幅，也不更改原声。

## 选方案与验收

默认三套短方案，写重点、开头/中间/结尾、关键结果、来源与限制。改变实质路线，不只换左右脸；不足三种不凑数。用户已选/要求直接完整稿时直接执行。talk不强转use，上脸不暗改手背。

选定后交拍摄表和完整稿，不增审批。拍摄表列原声语义段（可靠才写精确时间）、动作、结束状态、后续保持、验收点。转头展示的验收是“效果仍存在并看清”，不是“头转了”。

产品效果以本品依据为准，膏痕消散不等于妆效消失，光泽不证明吸收/不黏，长期功效不瞬变。入口能力先核对，未上传参考不能虚构@视频。成片按表复查，失败走[失败分析](review.md)。
